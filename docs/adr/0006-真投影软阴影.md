# 机壳投出真软阴影，接影面只吃阴影不改保真

机身下面那团影子从「机底接触阴影」（贴在机底的一块渐变贴片）升级成**真投影**：key 灯兼职投影灯，机壳把它的光挡在机身背后一块**只吃阴影的接影面**上，影子的形状随机身姿态实时重算。接影面用 `ShadowMaterial`，它不参与光照，只在被挡住的像素上压一层暗——机身自身的材质响应和[保真](../../GLOSSARY.md)基准一个像素都不动。

## Context

ADR-0004 给页面加的额外层只允许「机底接触阴影」这一种，且写法是贴在机底、跟着机身走。它在机身**平放、正对**时够用，但拖拽转到侧向大角度时，贴片是个不会变形的矩形，影子的方向和形状都跟机身对不上，看得出是「贴上去的」而不是「投出来的」。要的是拖拽转动时影子跟着几何重算。

## Decision

- **key 灯兼职投影灯**：`key.castShadow = true`，只多渲一遍深度图，不改灯自身对材质的贡献——三盏灯的数量、颜色、强度、位置一律不动，ADR-0004 的灯断言继续成立。
- **接影面挂在 `scene` 上，不挂 `rig`**。它代表「机身背后那面墙」，机身转动/缩放时墙不动，影子才会随几何重算；挂 `rig` 就退化成跟着机身转的贴片，等于没换做法。
- **接影面只吃阴影**：`THREE.ShadowMaterial` + `receiveShadow`，本身不反光、不参与光照，所以机身亮度与保真色块不受影响。它是全画布唯一新增的不透明像素，机身外空场保持全透明。
- 投影相机正交半宽 `SHADOW_SPAN = 12`（机身 |x| ≤ 5.02 × 最大 1.6 倍缩放，留够边距），深度图 1024²，`VSMShadowMap` 走软边（`radius = 18`）。
- 机身上每个 mesh 都 `castShadow = true`（机壳全件投影），`machineStatus()` 暴露 `casters` 数便于验收。

## Consequences

- 影子随姿态实时重算，拖拽到侧向大角度时方向和形状跟得上机身。实测机下条带 alpha 峰值 ≥ 60、机身左下空场不被涂满（有方向），画布四角 `alpha === 0`。
- 接影面贴到机身最后沿之后（`z = -1.30`，机身后沿 `z ≈ -0.52`），所以它只在机身背后，不会盖到机身或牌桌上。
- ADR-0004 的「唯一允许的额外层是机底接触阴影」这条**被本 ADR 取代**：额外层扩为「机底接触阴影 + 真投影接影面」，两者都只压暗、不改写模型材质响应；ADR-0004 的禁 IBL / 禁 ACES / 输出颜色空间对齐 `/glb` 这些保真约束继续有效。
- 旧的机底接触阴影贴片本轮**保留**，与真投影叠加使用。
