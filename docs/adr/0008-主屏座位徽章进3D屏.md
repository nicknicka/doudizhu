# 主屏座位徽章画进 3D 真屏，DOM 退成锚点

机身正面那块**主屏**上的座位张数徽章不再靠 2D HTML 盖在画布上：徽章画进一张 canvas 纹理，和屏内画面（牌桌离屏画面）一起合成到主屏纹理里。`#screen-hud` 那层 DOM 保留，但只用来**量尺寸和当验收锚点**，并保留悬停展开的完整卡片；`is-3d` 就绪后圆点 `opacity:0`。

## Context

ADR-0002 把座位牌留在 2D，ADR-0005 已经把**副屏**内容搬进 3D 玻璃面。主屏上的座位圆点是最后一处"贴在机身外侧"的覆盖层：HTML 永远画在画布最上层，机身一被拖动旋转，圆点就浮到屏外面（甚至转到背面还能看见）。这是「贴在外侧」和「嵌在里面」的必然差别，不是参数没调对。

## Decision

- 主屏 HUD 用一张铺满视口的透明平面 + 正交相机，在同一个离屏 RenderTarget 里**续画**在牌桌画面之上（不清屏），再整体贴到主屏。
- 纹理按主屏长宽比固定（1536×804 ≈ 104×54.4），颜色走 sRGB、`generateMipmaps:false`、`toneMapped:false`，与页面底色一致。
- 圆点大小照 DOM 那颗 28px 圆点实测宽折算，CSS 一改纹理跟着变，不各写一个常量。
- DOM 那层退成**几何锚点**：`is-3d` 时圆点 `opacity:0`，只有悬停才浮出完整卡片——那是「要读的字」，不是屏内标记。

## Consequences

- 圆点随机身一起转、被凸边框遮挡（`depthTest` 默认开），翻到背面看不见。
- 圆点变成贴图：不可选中、缩放会软。ADR-0002 里「数字要一眼读准」这条对**主屏座位圆点**让位给「嵌进机身」；座位名/身份这些要读的字仍走 DOM 悬停卡片，不受影响。
- 部分取代 ADR-0002「座位牌留 2D」这一条；其余部分（机身/牌桌 3D、机侧/机下数据面板 2D）继续有效。
