# 机身用 three.js 做 3D，文字面板留在 2D

展示页的牌桌做成一台像素游戏机：**机身、牌桌**用 three.js（WebGL）渲染成真 3D；而**记牌器、概率、校准这些要读的数字**仍是平面 HTML，贴在机身外侧。

选它是因为两类内容的诉求相反：机身和牌桌要的是空间感，数字面板要的是**一眼读准**。把面板也塞进 3D 会让中文点阵字在透视里发糊，而 CSS3D 与 WebGL 之间没有深度遮挡、谁挡谁要手工算 —— 换来的只是"更整体"这一条。

## Considered Options

- **纯 CSS 3D 变换**：不引依赖、与像素边框最搭；但没有真光照、做不出机身几何，机身靠 div 层叠，层一多就卡。
- **全 WebGL（文字也做画布贴图）**：视觉最统一；但文字变成贴图 —— 缩放发糊、不可选、不可访问，且每处交互都要靠射线拾取。

## Consequences

- 面板是 2D，所以**窄屏只需重排、不必重画**一套 3D：窄屏固定正视角、面板纵向堆叠，不额外维护第二套版式。
- 镜头只做**跟随鼠标的轻微视差**，不做可拖拽的轨道旋转 —— 机器背面没有内容，且拖拽会与"点牌"抢手势。
- 机身、机顶记牌器、机侧面板是**一件整体**，不是"一个 3D 装饰 + 一个普通网页"。
