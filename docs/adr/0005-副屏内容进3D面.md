# 副屏内容画进 3D 玻璃面，DOM 退成几何锚点

机身顶部的**副屏**（显示屏里那条窄屏）不再靠 2D HTML 盖在画布上显示内容：内容画进一张 canvas 纹理，贴到副屏玻璃面本身的一张真 3D 平面上。`#counter` 那层 DOM 保留，但只用来**量尺寸和当验收锚点**，就绪后 `opacity:0`。

## Context

ADR-0002 把记牌器/概率留在 2D，理由是数字要一眼读准。实际做下来，副屏是**嵌在机身里的**、还要随拖拽一起转：2D 覆盖层永远画在最上层，机身转起来它的位置和透视都对不上——凸边框挡不住它，翻到背面还能看见内容。这是「贴在外侧」和「嵌在里面」两种做法的必然差别，不是参数没调对。

## Decision

- 量**玻璃面本身**（`SubDisplay_1` 网格）的盒子，把平面贴到它的前沿（`max.z + 0.02`）。量整组 `SubDisplay` 会带上凸边框（z 9.82 vs 玻璃面 9.47），贴上去会浮出一圈。
- 纹理按玻璃面长宽比固定（1216×80 ≈ 113.90×7.50），不随视口重画；颜色走 sRGB、`toneMapped:false`，与页面底色一致。
- 内容**一份数据两处用**：`counterModel()` 算一遍，3D 纹理和 DOM 都从它渲染，不各算一次。

## Consequences

- 副屏随机身一起转、一起被遮挡（`depthTest/depthWrite` 默认开），背面看不见内容。
- 记牌/概率的字变成了贴图：缩放会软、不可选中。ADR-0002 里「数字要一眼读准」这条对**副屏**让位给「嵌进机身」；贴在机身外侧的机侧/机下数据面板仍是 2D HTML，不受影响。
- 部分取代 ADR-0002「机顶记牌器是 2D 文字面板」这一条；其余部分（机身/牌桌 3D、机侧面板 2D）继续有效。
