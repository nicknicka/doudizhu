# 首屏动画采纳 SpinKit 折叠立方体，常规态不写字

加载层里的动画不自己写：采纳 SpinKit 的 `.sk-fold`（MIT、纯 CSS、零 JS），上游字节原样内联。加载层在常规态**不写任何字** —— 说明由动画说；文字只在失败态与读屏出现。

## Context

ADR-0009 定了加载层由标记承载、不等模块脚本。剩下的两个问题在 #55 里逐支比过（13 个候选，全部纯 CSS、退场机制共用）：

1. **动画自己写还是采纳现成的**：自己写能精确贴语言，但等于自己维护一段动画；现成库里绝大多数要么要 JS 模块，要么样式锁在 shadow DOM 里，而加载层的第一条约束是"不等模块图"。
2. **要不要给动画配一句说明**：评审里最容易滑向"正在加载…"加上候选名这种副标题。一旦成立，加载层就变成"用文字解释设计"，而它是全站第一眼看到的东西。

## Decision

- **动画采纳 SpinKit 的 `.sk-fold`**：四个方块在 `perspective(140px)` 里依次折叠，2.4s 一轮，上游数值一个没改。整份库 vendored 在 `web/vendor/spinkit.min.css`，许可全文在 `web/vendor/LICENSE-spinkit.txt`；模板里只内联用得上的 10 条规则。**不用 `<link>` 引它**：样式表会阻塞首帧，与 ADR-0009 直接冲突。本项目这一侧只给 `--sk-size` / `--sk-color`。
- **常规态零文字**：加载层里没有"正在加载…"，也没有候选副标题。文字没有删掉 —— 它沉到 sr-only（1×1 + `clip-path:inset(50%)`），`aria-live="polite"` / `aria-busy="true"` 留在容器上。
- **失败态必须看得见**：模块没起来时兜底脚本把文字放回来并给出「重新加载」；8 秒强放行走顶部横幅。报错是信息，不是装饰。
- **退场编排进兜底脚本**：`__bootHandoff` 先加 `is-exiting` 播 0.26s（收成一条线），再摘掉 `is-booting`；模块脚本与看门狗调的是同一个入口。

## Considered Options

- **自己写纯 CSS 3D**（立体方块 / 翻牌 / 透视扫描台）：可控、能精确贴语言，但等于自己维护动画代码 —— #55 里逐支比过之后选了上游。
- **采纳 ldrs（web component 库）**：40 多支、MIT、作者活跃，但单支 `quantum` 的实际载荷是 2,510 + 4,812 + 816 = 8,138 字节 / 3 个模块，样式在 shadow DOM 里要重画，且模块到齐前加载层是空白 —— 对"首帧就显示"的加载层不合适。
- **用项目里已有的 three.js 画真 3D**：加载层不能等模块图（`three.module.min.js` 753KB），three 只能用在机身出现之后。
- **给动画配一句说明文字**：拒绝 —— 说明由设计说；文字只留给失败态与读屏。

## Consequences

- 加载层不再需要本仓库维护任何动画代码：上游文件 + 许可 + 6 行本项目样式；升级路径是替换 `web/vendor/spinkit.min.css` 并同步内联的那几行。
- 零文字意味着"还在等"完全靠动画表达，弱网下唯一的文字兜底是 8 秒后的顶部横幅。
- `web/verify.mjs` 多了两条断言：常规态不得有可见文字、模块挂掉必须放出报错文字与重试入口 —— 以后改加载层会被挡一次。
