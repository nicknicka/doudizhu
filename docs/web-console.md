# 展示页：像素游戏机（设计共识）

把展示页重做成一台**像素游戏机**。术语以 [GLOSSARY.md](../GLOSSARY.md) 为准；两条硬决定见
[ADR-0001](adr/0001-合法性由服务端裁定.md) 与 [ADR-0002](adr/0002-机身用3D-文字面板留2D.md)。

## 版式：一件整体

```
        ┌──────────── 机顶：记牌器 ────────────┐
        │  15 个点数 × 还没现身的张数           │
   ┌────┴───────────────────────────────┬────┴────┐
   │            机身（3D）               │ 机侧     │
   │  上家[身份]          下家[身份]      │ CRT 面板 │
   │   牌背                牌背          │ 粒子云   │
   │           牌桌 / 上一手              │ 逐张概率 │
   │        我[身份] · 我的一手（正面）    │ 校准     │
   └────────────────────────────────────┴─────────┘
        ┌──────────── 机下：操作台 ────────────┐
        │ 出牌机会 ①②③… │ 牌盘 │ 出牌/不要/撤销 │
        └──────────────────────────────────────┘
```

- 机身、机顶记牌器、机侧面板是**一件整体**，不是"一个 3D 装饰 + 一个普通网页"。
- 机身、三位角色、三副牌、牌桌由 three.js 渲染成真 3D；**要读的数字仍是平面 HTML**（ADR-0002）。
- 只有**我的一手**是正面，另两家是牌背 + 张数。

## 语言

- 座位名一律以**我方**为参照：我 / 上家 / 下家；位置也跟着以我方为参照 —— **我在最下**，两个对手在上。
- 地主、农民是**身份徽章**，不是座位名 —— 两者正交。
- 决策点对人一律叫**第 N 次出牌机会**；**全局手数**降级成小字（复盘时对齐记录用）。
- 粒子云的图例用 上家/下家，不再漏内部英文 id。

## 交互

- **镜头**：跟随鼠标的轻微视差 + 开场推镜。不做轨道旋转（机器背面没有内容，且拖拽会与点牌抢手势）。
- **录牌**：牌盘点选；轮到我方时，模型排好序的候选**点一下就记下这一手**。
- **牌盘的约束**：选牌不超过**牌池**里该点数的剩余张数；牌型与压制一律由服务端在提交时判（ADR-0001）。
- **牌盘的计数**：键面只写点数，张数做**右上角上标**，0 不显示。
- **窄屏**：保持 3D，固定正视、面板纵向堆叠；不维护第二套 2D 版式。

## 角色

三位角色用**扑克牌拟人**的像素精灵（花色元素 + 地主戴王冠），作公告板贴进 3D 场景。
先出 3 张站姿，构图定稿后再补"该他出牌"的动作帧。

## 分阶段

| 阶段 | 内容 |
|---|---|
| 1 | **快修（不依赖 3D）**：座位名改相对位置、决策点改"出牌机会"、牌盘加**牌池上限**、计数改上标 |
| 2 | 3D 机身 + 三位角色 + 三副牌 + 机顶记牌器 + 视差镜头（替掉现在的 2D 牌桌） |
| 3 | 机侧 CRT 面板：粒子云（补说明）+ 逐张概率 + 校准 |
| 4 | 操作台整合；可选：直接点 3D 桌上的牌来录 |

阶段 1 只改**将来会保留的 HTML 界面**（面板 / 操作台），且 3D 场景要用同一套词，所以不白做。

## 明确不做

- 不做可拖拽的轨道旋转（见上）。
- 不把斗地主规则搬进前端（ADR-0001）。
- 不在这一轮给角色做完整动画帧。
