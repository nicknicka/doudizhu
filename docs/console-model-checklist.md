# v5 修正 2（2026-11-03：用户反馈「侧面视角可以看到，黑边和主体有间隔」）

> 同样走「一个做 + 一个独立审查」；审查第 1 轮就判**达标**。

**根因**：`build_side_band()` 里正面那条深色像素环（`PixelOutline`）在 `y=-10.6..-10.46`，
而侧边带前端面在 `FRONT_Y=-9.5` → **Y 向 1mm 空档**；同时环内径 199.2 vs 侧边带前脸外径 196.4
→ **X/Z 每侧还有 ~2.8mm 空档**。两处叠加，3/4 视角就能看穿这条环与侧边带之间的空隙。

**改法**（只动 `build_side_band()`，+8/−1 行）：在侧边带前方补一层 `outer_lip`
（宽高 = 深色环内缘 + 一个 `PIXEL_STAIR_SIZE`），loft 前段变成
`outer_lip @ SHELL_FRONT-0.02 → outer_lip @ FRONT_Y → 原 outer_m` ——
米色带前缘直接顶住深色环内缘。常量（`OUTLINE_WIDTH / OUTLINE_OUTSET / PIXEL_STAIR_SIZE / SB_BEV / PIPE_W`）
与深色环几何都没动；背侧环本来就落在 `outer_m` 等宽段内、无空腔，未改。

**审查证据**（独立 agent，用 Blender 从 GLB 重渲 + 纯 alpha 判形 + 同机位 A/B）：
- 同机位（3/4）贯穿缝：旧版 **667 列 / 438 行**断裂（最大 87px）→ 新版 **3 列 / 9 行**（最大 1px / 33px）；
